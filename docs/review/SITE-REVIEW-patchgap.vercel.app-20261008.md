## 3. 마케팅 포인트
5단계 대조를 통과한 사례만 썼다. 잠수함 사례(렝가·덩굴정령·마오카이)는 UX #1~#3의 오탐 후보라 쓰지 않았다.

1. **패치노트 한 줄 한 줄을 "실제 게임 데이터"와 맞대어 세 칸으로 나눈다** — 말한 것 / 말하지 않은 것 / 값이 다른 것.
   - 사례: 18.1→18.2 덩굴정령 상세에서 노트는 "기본 공격력 115 ⇒ 120"인데 게임 파일은 "110 → 115"였다(공지값 불일치). 같은 쌍의 브리핑 Gap 탭에도 같은 값으로 나와 자기정합이 맞는다.
   - 덜 드러나는 곳: "값이 다른 것"은 브리핑 미공지 Gap 탭 안쪽 중간("패치노트와 값이 다른 것 대상 3종")에 묻혀 있고, 대조표에는 칩이 없다(UX #10).
   - 헤드라인: "패치노트에 적힌 숫자가 실제로 게임에 들어갔는지, 줄마다 확인해 드려요."
2. **"올랐다"는 말마다 표본과 오차를 같이 보여 준다** — 상세의 통계 게이트(n 전/후 보드, BH-FDR q, 바닥 대비), 95% CI 오차 막대, 원천 매치 ID, LLM 원인의 "신뢰도 낮음" 꼬리표(crawl2/03 full). 대조표 행 "50.7% → 58.0% +7.4%p"와 상세 수치가 일치한다.
   - 덜 드러나는 곳: 이 근거들이 상세에만 있고, 대조표 전체 보기에서는 근거 열이 1280폭 밖으로 밀린다(UX #13). 근거를 설명하는 방법론은 지금 열리지 않는다(UX #7).
   - 헤드라인: "감이 아니라 숫자로 — 몇 판을 보고, 얼마나 확실한지까지 보여 드려요."
3. **패치 당일에도 노트를 대상별로 정리해 원문 위치까지 링크한다** — /tft/ 18.4는 52대상 73줄을 묶고, 73줄 모두 공식 노트 #patch-large-changes 앵커로 연결된다(links.json 외부 73개 = "공지 73건").
   - 덜 드러나는 곳: 이 화면이 "관측 전"이라는 사실에 가려 지난 패치의 통계(18.2→18.3)로 이어지지 않는다(UX #6). H1은 대상 수를 "항목"이라 불러 73줄과 충돌한다(UX #5).
   - 헤드라인: "새 패치노트를 대상별로 정리했어요. 지난 패치에서 실제로 뭐가 달라졌는지도 바로 이어서 보세요."

관점 보충: 주말에 패치 내용을 확인하러 처음 온 게이머. 패치노트는 읽었고, 통계가 실제로 무엇이 달라졌다고 말하는지 궁금한 사람.

  - 대조표 "무기 검색" 입력은 조작하지 않았다.

## 3. 마케팅 포인트 (user)
아래 세 강점은 자기정합 대조를 통과했다.

1. **총이 덜 떨어진 패치에서도 '다 너프된 것처럼' 보이지 않게 점유율로 잰다**
   - 헤드라인: "이번 패치는 총이 매치당 474개 → 414개로 덜 떨어졌어요. 그래서 개수가 아니라 비율로 비교해요"
   - 대조 통과: 맵 7개 획득 총량 합(태이고 399.0k + 에란겔 129.3k + 사녹 47.2k + 미라마 48.0k + 파라모 17.2k + 카라킨 13.1k + 론도 13.3k = 667.2k)이 1,614매치 × 413 = 666.8k와 맞는다. 무기 n(전·후)과 점유율의 역산도 일치한다.
   - 덜 드러나는 곳: 474 → 414는 방법론에만 있고, 브리핑에는 "모든 수치는 매치당 총 획득 대비 점유율"이라는 작은 회색 한 줄뿐이다. 브리핑 히어로 아래 한 줄에 "총 드랍 −13% — 그래서 점유율로 비교합니다"를 숫자와 함께 보이면 전달된다.
2. **패치노트의 숫자가 실제 게임에서도 그만큼 나왔는지 맞춰 본다**
   - 헤드라인: "'RPD·M249 스폰 30% 감소', 실제로는 26%·25% 줄었어요"
   - 대조 통과: RPD −26.0% CI [−27.3%, −24.7%], M249 −25.2%. 관측/공지 비 0.87·0.84는 방법론의 공지 일치 밴드 0.5~1.5 안이다.
   - 덜 드러나는 곳: 브리핑 공지 행은 "RPD → 무기 1개 항목 ▾"뿐이라 30%와 26%를 나란히 볼 수 없다. 행에 "공지 −30% · 관측 −26%"를 바로 적으면 된다.
3. **재분배로 설명되는 몫을 빼고 남는 변화만 짚는다**
   - 헤드라인: "Beryl이 +15.7% 늘었어요. 스폰 줄인 총의 몫이 넘어온 것(+1.9%)만으로는 설명이 안 돼요"
   - 대조 통과: RPD·M249 점유율 감소분 (3.97 − 2.94) + (3.03 − 2.27) = 1.79%p를 나머지 약 93%에 균등 배분하면 +1.9%이고, 방법론 수치와 같다. Beryl은 노트에 없는 무기다(대조표 왼쪽 패널 3종 밖).
   - 덜 드러나는 곳: 이 비교는 상세 하단 "추정 원인(LLM)"에만 있고, 브리핑 미공지 행은 "Beryl M762 → 무기 1개 항목"뿐이다. 미공지 행에 "+15.7% (재분배 기대 +1.9%)"를 붙이면 된다.

### 세 게임이 이미 같은 것 (감점 없음, 근거만 기록)
- 헤더 골격: 로고 · 게임 선택 · `브리핑 대조표 방법론` · 패치 선택기 · 필터 칩 · 우측 메타. 패치 선택기 안내문("패치쌍을 고르면 그 쌍의 {메뉴}로 이동합니다")과 단일 쌍 문구도 같다. 모바일 내비도 같다(mobileInventory).
- 3타일 라벨(`공지된 변화`/`유의한 관측`/`미공지 Gap ↗`)과 탭 라벨(`패치 내용 N`/`미공지 Gap N`)이 같다.
- **타일 → 대조표 미공지 칩 착지가 세 게임 동일하다**: 추가 크롤 `crawl-parity/03·04·05`에서 `#unannounced`로 들어가면 `미공지 N [true]`가 켜져 있다.
- **미공지 Gap 타일 · 탭 · 대조표 칩이 다섯 쌍 모두 정합이다.** 식은 `탭 = 미공지 칩 + (전체 − 공지 − 이상 − 미공지)`이다. 아래 항등식 표 참조.
- 대조표 도구모음이 같다: 상태 칩 4종 + 개수 · 검색 · 정렬 3키 · 좌측 `패치노트 항목` 내비 + 우측 `선언 ↔ 관측`.
- breadcrumb가 같다: `브리핑 › 대조표 › {대상}` / `브리핑 › 방법론`.
- `패치 내용 N` 탭은 세 게임 모두 행별 "N개 항목"의 합이다(TFT 18.2→18.3 행 10개 → 14, PUBG 2 → 2. LoL 233은 접힌 묶음 때문에 다 더할 수는 없었다).
- 상세 관측 섹션이 같다: 지표 탭 × 구간(또는 "구간 축 없음 — 사유") · 뱃지 · 전→후 · 막대 · 통계 게이트 · 원천 매치 · 집계 경로 · 판정 규칙 링크 · 추정 원인(LLM).
- LoL과 PUBG 방법론은 9슬롯 H2 순서가 같다.
- 푸터 구성이 같다: 집계 KST · 판정 N건 · 데이터 출처 · 정상 운영/빌드 · 퍼블리셔별 고지.

## 3. 마케팅 포인트 (통일성 관점, 자기정합 대조를 통과한 것만)
1. **"한 번 배우면 세 게임 다 읽힌다" — 대조표 도구모음과 숫자 연결.** 칩 4종 + 개수, 검색, 정렬 3키, 좌측 패치노트 내비가 세 게임에서 같은 자리에 있다. 타일 `미공지 Gap ↗`을 누르면 세 게임 모두 미공지 칩이 켜진 대조표로 간다(crawl-parity 03·04·05). 타일 수 = 칩 수 + 수치 축 대상 수도 다섯 쌍 모두 맞는다. 덜 드러나는 지점: `↗`만 있고 "대조표에서 미공지만 보기"라는 말이 없다.
   - 헤드라인: "어느 게임이든 숫자를 누르면 같은 표로 데려가요"
2. **상세 관측 패널이 세 게임 공통 문법이다.** 지표 탭 → 뱃지·전후·막대 → 통계 게이트 → 원천 매치 → 추정 원인 순서다. 덜 드러나는 지점: LoL 상세만 폭이 좁아(S22) 같은 패널인지 첫눈에 알아보기 어렵다.
   - 헤드라인: "챔피언이든 유닛이든 총이든, 근거는 같은 자리에 있어요"
3. **헤더 하나로 게임과 패치를 바꾼다.** 게임 선택과 패치쌍 선택기의 위치·문구가 세 게임 동일하다. 덜 드러나는 지점: 게임을 바꾸면 TFT는 관측 전 최신 쌍에 착지해(S2) 이 장점이 첫 화면에서 끊긴다.
   - 헤드라인: "보던 메뉴 그대로, 게임만 바꿔 보세요"

## 가장 먼저 고칠 1가지
최신 쌍이 관측 전이면 브리핑·대조표·방법론이 계약 골격 대신 스텁을 렌더한다(S2·S1·S3). 게임 선택으로 TFT에 처음 들어오는 화면부터 3타일·탭·사이드·푸터가 사라지고, 방법론은 어느 쌍에서 들어가도 비어 있다. 관측 전에도 골격과 9슬롯을 유지하고 "—"와 사유만 채우면 된다.

## 부록 — 세 게임 공통 계약 위반 (통일성 감점 없음, 검증명세 제외)
- **수치 축 행의 뱃지 위치**: 세 게임 모두 이름 **뒤**에 둔다(`엘리스 [잠수함 패치]`, `다이애나 → [잠수함 패치]`). §8-1은 "행 맨 앞".
- **상세 문구의 내부 용어**: 세 게임 모두 "이 엔티티에는 없습니다"·"이 엔티티를 언급한…"을 쓴다. §8-5.
- **방법론 해석표 첫 열 헤더**: LoL·PUBG 모두 `상태`다. §8-5 "판정 열 헤더 `판정`". TFT는 관측 전이라 표가 없다.
- **`패치 내용 N` 탭·섹션 "N건"**: 세 게임 모두 대상이 아니라 행별 항목의 합을 센다(TFT 행 10개에 14). §8-2 "세는 단위는 대상".
