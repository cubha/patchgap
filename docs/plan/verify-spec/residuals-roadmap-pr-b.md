## B2 — C7 중간 패치 체이닝
- 변경: `tft-notes-parser.ts` `chainMidpatchUpdates` — `#patch-midpatch-updates` 줄이 본 패치 줄과 (대상·수치 이름 같음, 중간 패치 before = 본 패치 after)이면 한 줄의 순변화로 잇는다. 요약에 두 단계를 다 남기고 앵커는 중간 패치.

- 변경: `combined-note-split.ts` `splitCombinedNotes` — 합친 이름의 core 아이템 노트 묶음에서, DDragon 스탯 키가 있는 수치(체력 등)로 **바뀐 단계마다 이전·이후 값이 유일하게 맞는 아이템**을 찾아 배정. 하나라도 안 맞으면 현행 유지. - 실측: 26.19 「세계 지도집과 룬 나침반」 체력·체력 재생 2줄 → 4줄(세계 지도집 체력 30⇒0 nerf · 룬 나침반 100⇒60 nerf · 재생 25%⇒50% · 50%⇒75% buff). 3단계(세계의 결실 200⇒200·75%⇒75%)는 안 바뀌어 빠진다.
