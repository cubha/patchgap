- 변경 요약: `PubgNoteClauses`(신규) — 「패치노트 조항 N건」 목록(대상 무기 · 요약 · 원문 ↗), 기대값 없는 조항은 `text-muted` + 「이 데이터로 측정 불가」. `PubgBriefing` 패치 내용 탭의 커버리지 줄 아래.
