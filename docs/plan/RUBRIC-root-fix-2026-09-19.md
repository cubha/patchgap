# 채점표 — 결정 7건 근본해결 + 추가 5건 (2026-09-19)

채점은 **구현자와 독립된 에이전트**가 로컬 정적 빌드 실렌더로 수행한다. 과대평가 방지가 목적이므로
근거 없는 점수는 주지 않는다. 항목마다 근거(라우트·셀렉터·측정값·파일:라인)를 적는다.

- 총점 100 = K1 25 + K2 25 + K3 25 + K4 25
- 측정 불가 항목은 분모에서 제외하고 "측정 불가"로 따로 적는다.
- 방법론 페이지(`/methodology/`·`/pubg/methodology/`)는 K4의 "설명 문단 금지" 대상에서 **제외**된다
  (방법 서술의 집이다).
