# 치장 항목 이미지·정보 표시 — 가능여부 판정 (2026-09-17)

> 사용자 지시 B4 후반부: "신규스킨이나 챔피언, 아이템 등 패치내용을 간략하게 정보 및 이미지를
> 볼 수 있도록 **개선 가능한지 여부 확인**". 요청이 "확인"이므로 이 문서가 산출물이고, 구현은
> 착수하지 않았다(PLAN-gap-display-unify §5 X3).

**결론: 가능하다. 단 커버리지가 절반이고, 나머지 절반은 "자산이 없다"가 정답이다.**

---

## 1. 결정적 근거 — 노트 문구가 Data Dragon 스킨명과 **글자 그대로** 일치한다

26.18 `홀 오브 레전드` 노트에 적힌 이름을 ko_KR Data Dragon 스킨 목록과 대조한 실측:

| 노트 문구 | Data Dragon | 스플래시 경로 |
|---|---|---|
| 떠오른 전설 오리아나 | `Orianna` skins[40] `"떠오른 전설 오리아나"` | `img/champion/splash/Orianna_40.jpg` |
| 프렐요드 탈리야 | `Taliyah` skins[1] | `Taliyah_1.jpg` |
| 나무정령 르블랑 | `Leblanc` skins[5] | `Leblanc_5.jpg` |
| 창공 아칼리 | `Akali` skins[82] | `Akali_82.jpg` |
| 불멸의 전설 트리스타나 | `Tristana` skins[80] | `Tristana_80.jpg` |
| 떠오른 전설 트리스타나 | `Tristana` skins[79] | `Tristana_79.jpg` |

**추측 매칭이 필요 없다** — 부분문자열 정확 일치로 잡힌다. 이것이 이 판정의 핵심이다.
이름을 유추해야 했다면 "가능하지만 위험하다"였을 텐데, 실제로는 결정론적이다.

## 2. 커버리지 — 26.18 `홀 오브 레전드` 10줄 기준

| 잡히는 것 (4/10) | 못 잡는 것 (6/10) |
|---|---|
| 떠오른 전설 오리아나 스킨 및 테두리 | 신화 정수 125개 |
| 떠오른 전설 오리아나 이벤트 크로마 * | 구 11개 |
| 프렐요드 탈리야·나무정령 르블랑·창공 아칼리 스킨 (3종) | Caps 선수 테마 아이콘 및 감정표현 15개 |
| — | 불사의 악마 선인장 와드 · 희망의 등불 휘장 · '마르틴 1' 칭호 · 그 외 다수! |

\* 크로마는 Data Dragon에 **자산이 없다**(스킨만 있다). 기본 전설 스킨 스플래시로 대체하면
"크로마를 보여준다"는 거짓이 되므로, 크로마 줄은 **이미지 없이 텍스트만** 두는 편이 맞다.

**못 잡는 6줄의 공통점**: 아이콘·감정표현·와드·휘장·칭호·정수는 Data Dragon 배포 범위 밖이다.
이건 매칭 실패가 아니라 **자산의 부재**라, 어떤 구현으로도 해결되지 않는다. 화면에서는
"이미지 없음"이 정확한 상태다(만들어 내지 않는다).

## 3. 구현 비용

| 항목 | 내용 | 비고 |
|---|---|---|
| 스킨 인덱스 | 챔피언별 상세 JSON(`cdn/{ver}/data/ko_KR/champion/{Id}.json`)에 skins[] 존재. **번들 `champion.json`에는 없다**(실측: keys에 `skins` 없음) | 치장 노트에 등장하는 챔피언만 받으면 26.18 기준 4건 |
| 스플래시 자산 | `img/champion/splash/{Id}_{num}.jpg`, 장당 130~160KB | 선례 있음 — `public/dd/splash/`에 173장(`_0`만) 이미 커밋 중 |
| 매칭 로직 | 스킨명 → 노트 요약문 부분문자열 **최장 일치**. 동률·미일치는 이미지 없음 | 순수 함수 + 테스트 |
| 파이프라인 | `scripts/run-ddragon.ts` 확장(빌드 타임) — 런타임 외부 호출 0 유지 | |
| 렌더 | 치장 카드에 썸네일 + 스킨명. 뱃지는 이미 제거됨(이번 라운드 B4 전반부) | |

예상 규모: 신규 파일 2개(매칭 순수 함수 + 테스트), 기존 2개 수정, 자산 수 장.

## 4. 권고

**하되, 범위를 "스킨"으로 명시해서 한다.** "신규 스킨·챔피언·아이템을 본다"로 넓히면
크로마·아이콘·와드에서 반드시 빈칸이 생기고, 그 빈칸이 다시 "왜 안 나오냐"가 된다.
화면 문구를 **"스킨 미리보기"**로 좁히면 4/10이 결함이 아니라 정의가 된다.

이번 라운드에서 이미 끝난 부분(뱃지 제거)만으로도 원래 지적("관측 불필요한데 뱃지가 붙는다")은
해소된다. 이미지는 **추가 개선**이므로, 지시가 있으면 다음 라운드에서 착수한다.

재현: `curl -s "https://ddragon.leagueoflegends.com/cdn/16.18.1/data/ko_KR/champion/Orianna.json"`
