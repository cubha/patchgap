## 확정 제약
- 이월 목록에는 사람 결정·외부 조건만 남긴다. 내가 돌릴 수 있는 검증과 새 구현이 만든 한계는 이번에 닫는다.
- `any` 금지 · 신규 의존성 금지 · `data/raw`·`.env`·키 커밋 금지 · 사용자 dev 서버 기동 금지(검증용 정적 서버는 `out/`을 127.0.0.1 임시 포트로, 끝나면 종료).
- 테스트 변경은 명세 변경일 때만, 보고한다.
- force-push main 금지 · `--no-verify` 금지.
