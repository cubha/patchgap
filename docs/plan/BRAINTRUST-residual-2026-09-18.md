### 2-1. 충돌 규모 (공지짝 96행 전수 재계산, qAlpha=0.1)

### 2-2. 사유 문장이 사실과 다르다 (B2 축, E1/B2 만점이 놓친 것)

### 2-3. 권고 — 순수 함수 1개로 닫는다 (판정 엔진 불변)

`streamVerdict.ts`는 두 게이트를 **모두 아는 유일한 모듈**이고, `buildNoteVerdict`가 이미 어휘를 확정해 뒀다
(`"유의차 없음"` vs `"변화 규모 바닥 미달"`, `streamVerdict.test.ts:158`이 그 경계를 테스트로 고정).
카드 헤더만 그 계산을 안 하고 상수를 쓴다.

```ts
export type NoObservationReason = "no-pair" | "not-significant" | "below-floor" | "mixed";
export function explainNoObservation(rows, qAlpha?): NoObservationReason
// 짝 0 → no-pair · 전부 !sig → not-significant
// sig인 것이 전부 !floor → below-floor · 섞임 → mixed
const NO_OBS_LABEL = {
  "no-pair":         "짝지은 관측 없음",
  "not-significant": "관측 변화 없음 · 유의차 없음",
  "below-floor":     "관측 변화 없음 · 변화 규모 바닥 미달",
  mixed:             "관측 변화 없음",   // ← 사유를 단정하지 않는다
};
```
`mixed`에서 사유를 비우는 것이 핵심 — 6건 중 5건이 혼재라 한 사유를 고르면 그게 지금의 거짓말이다.
> ~~부수 효과로 E2도 +1~~ — **철회**(advisor 지적). E2의 측정은 *"첫 10행 중 '관측 없음'류 문장 **비율**"*이다.
> 네 라벨 중 셋이 여전히 "관측 변화 없음"으로 시작하고 넷째도 같은 부류라 **비율은 변하지 않는다**.
> "반복이 깨진다"는 육안 인상이지 E2가 재는 값이 아니다. ⇒ **A4 +1 · E2 +0.**

## 7. 렌즈 간 충돌과 조정

- **X1 점수 탄력성**: 렌즈4는 "A3는 섹션 순서·정렬을 재므로 X1은 +0, 기각"이라 했고 렌즈5는 실측으로 "폭 역전은 발견<증빙 배치라 A3 정면 위반"이라 했다.
  ⇒ **조정**: 렌즈4의 A3 독법이 문자적으로 옳다(폭 역전은 E1 소관). 그러나 그 결론은 **E1 6/6이 맞다는 전제** 위에 있고, 렌즈5가 그 전제를 깼다.
  결국 "X1로 A3를 올린다"는 틀렸고 "폭 역전은 E1이 놓친 결함이다"가 맞다 — **고치는 이유는 점수가 아니라 결함이기 때문**이다.
- **A4 해법**: 렌즈3 "기존 `buildNoteVerdict` 재사용"은 과소 명세다(그 함수는 **행 1개**용, 카드 헤더는 **행 묶음**). 렌즈1의 `explainNoObservation`(mixed 포함)이 정확하다. 어휘는 렌즈3 말대로 기존 것을 그대로 쓴다.
- **E2 회수 여부**: 렌즈3 "문구가 갈라지면 반복이 깨져 E2 +1" ↔ 렌즈4 "E2는 **비율**을 재므로 +0".
  ⇒ **조정: 렌즈4가 옳다.** 측정 방법 원문이 "첫 10행 중 '관측 없음'류 문장 비율"이고, 네 라벨이 전부 같은 부류라 비율 불변.
  (이 충돌은 초안에서 누락됐다가 advisor 외부검증에서 잡혔다.)
- **만장일치 없음**: 5렌즈가 서로 다른 결론에 도달했고 세 건이 실제로 충돌했다 — 공통 전제가 검증 없이 통과한 경우는 아니다.
